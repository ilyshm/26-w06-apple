# 🍎 사과게임

상하좌우로 붙어 있는 숫자를 드래그해 합이 10의 배수가 되도록 만드는 퍼즐 게임입니다. 60초 안에 최대한 많은 숫자를 수확해 높은 점수를 기록해 보세요.

## 게임 소개

8x8 격자에 1부터 9까지의 숫자가 무작위로 배치됩니다. 인접한 숫자를 한 번씩 이어 선택한 뒤 손을 떼었을 때 합이 10, 20, 30처럼 10의 배수이면 선택한 타일이 사라지고 숫자 합만큼 점수를 얻습니다. 제거된 칸에는 새 숫자가 채워집니다.

게임 시작 버튼을 누르면 60초 동안 진행되며 현재 점수와 최고 점수가 화면에 표시됩니다. 사과를 수확하면 위쪽 사과가 아래로 내려오고, 최고 점수는 브라우저의 `localStorage`에 저장됩니다. 최고 점수를 새로 기록하면 화면에 컨페티 효과가 나타납니다.

## 어떻게 만들었나요

HTML, CSS, Vanilla JavaScript로 구현했습니다. 별도의 프레임워크나 외부 라이브러리 없이 Pointer Events를 사용해 마우스와 터치 드래그를 모두 지원합니다.

## 실행 방법

저장소의 `index.html`을 브라우저에서 직접 열면 실행할 수 있습니다. GitHub Pages에서는 `index.html`, `style.css`, `script.js`를 같은 경로에 업로드하면 됩니다.

## 커스터마이징한 부분

- 8x8 격자와 60초 제한시간을 적용했습니다.
- 합이 정확히 10뿐 아니라 20, 30 등 모든 10의 배수를 허용했습니다.
- 상하좌우 4방향 드래그 선택을 지원합니다.
- 최고 점수를 `localStorage`에 보존합니다.
- 모바일 화면에서도 사용할 수 있도록 반응형 레이아웃과 터치 입력을 추가했습니다.
- 게임 시작 전 대기 상태를 추가해 시작 버튼을 눌러야 타이머가 작동하도록 했습니다.
- 숫자 타일을 사과 아이콘과 숫자 배지로 표현했습니다.
- 수확한 칸 위의 사과가 아래로 내려오는 열 단위 낙하를 구현했습니다.
- 최고 점수 갱신 시 컨페티 애니메이션을 보여줍니다.
